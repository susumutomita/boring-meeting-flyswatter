# ハエ叩きゲーム付き会議退屈度メーター 仕様メモ

## 概要

会議中の無操作・無発話に相当する「空白時間」を、ブラウザ上の退屈度メーターとして表現する。
一定時間アクティビティが途切れると、軽い介入としてハエ叩きゲームが起動し、その回数とプレイ結果を会議の退屈度として可視化する。

## ユーザーストーリー

- ハッカソンのデモを見る来場者として、会議の退屈さがどのように行動データへ変換されるかを直感的に体験したい。
- 会議改善に関心のある人として、単なるジョークで終わらず、会議品質の指標としてどう見えるかをその場で把握したい。

## 受け入れ基準

- [ ] 会議開始後、一定時間アクティビティがないと退屈度が上がる。
- [ ] 退屈度がしきい値に達すると、ハエ叩きゲームが起動する。
- [ ] ハエを叩くとスコアが増え、ゲーム内のハエが再配置される。
- [ ] 退屈イベント数、初回発生時刻、平均スコア、退屈率が画面上で確認できる。
- [ ] 会議を開始していない状態、会議監視中、ゲーム介入中の 3 状態が視覚的に区別できる。

## 非機能要件

- パフォーマンス: ローカルブラウザで軽快に動作すること。
- アクセシビリティ: ボタン操作だけでも進行でき、各操作要素にラベルがあること。
- デザイン: ピッチデッキのノリを壊さず、記憶に残る強いビジュアルであること。

## 技術設計

- フレームワーク: Vite + React + TypeScript。
- 状態管理: 純粋関数ベースの会議状態遷移ロジックを `src/lib/meeting.ts` に集約する。
- UI: 単一ページで、ヒーロー、ライブメーター、アクティビティ操作、ミニゲーム、メトリクス一覧を構成する。
- テスト: 退屈検知、アクティビティリセット、ハエ叩きスコア、メトリクス算出を `bun test` で検証する。

## スコープ外

- 実際のマイク入力や OS レベルの操作検知。
- 複数人参加や会議履歴の永続化。
- 外部ツール連携やダッシュボードのバックエンド。
